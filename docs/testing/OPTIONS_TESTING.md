# Risk of Options support

Install [Rune580-Risk_Of_Options](https://github.com/Rune580/RiskOfOptions) separately. Open Settings → Mod Options → Risk of Rain Upscaling.

| Control | Choices / range | Behavior |
| --- | --- | --- |
| Upscaler | Auto, DLSS, FSR | Applies next frame with a history reset. Auto uses DLSS on supported NVIDIA GPUs and FSR on other GPUs. Explicit DLSS on another vendor turns reconstruction Off and logs `UPSCALER_UNAVAILABLE`. |
| Upscaler Quality | Off, DLAA, Quality, Balanced, Performance, Ultra Performance | Applies next frame. Rebuilds render targets and resets reconstruction history. When the Upscaler resolves to FSR, the DLAA choice is labeled Native AA (the config value stays `DLAA`) and runs FSR Native AA; the label follows Upscaler changes while the menu is open. FSR Balanced renders at 1/1.7 (59%) instead of 58%. |
| Frame Generation | Off, 2x, 3x, 4x, 5x, 6x | Off/on and multiplier changes apply on the next eligible frame while D3D12 is active. Enabling from D3D11 prompts for a restart. Live Off retains D3D12 for the session; restarting with Off saved starts native D3D11 presentation. Unsupported multipliers use the highest supported GPU/driver mode, reported in the overlay/log. Pausing still suspends generation until resumed. FSR Frame Generation runs every enabled choice at 2x. |
| Frame Generation Backend | Auto, DLSS, FSR | Prompts for a restart; the preloader reads it before graphics startup. Auto uses DLSS Frame Generation on supported NVIDIA GPUs and FSR Frame Generation on other GPUs. |
| Outlines | Full Resolution, Temporal | Greyed out at DLAA/Native AA and while upscaling is Off. Rebuilds the upscaler with a history reset; `UPSCALER_ATTACHED` logs `outlines`. Temporal needs DLSS alpha upscaling, so FSR draws Full Resolution either way. |
| DLSS Preset | Default, K, M, L, J, E | Greyed out unless upscaling is on and the Upscaler resolves to DLSS. Rebuilds the upscaler with a history reset; `UPSCALER_SELECTED` logs `dlssPreset` (sl::DLSSPreset value, 0 = NVIDIA default per mode). Labels show the model family (transformer or CNN). |
| RCAS Sharpening | 0–1, steps of 0.01 | 0 disables sharpening. Changes on the next rendered frame without resetting DLSS history. Applies while DLAA/DLSS is active. |
| Framerate Limit | Shared game FPS setting | Shows the game's current limit. Changing either menu changes the same setting immediately. -1 is unlimited, matching the game. Uses Reflex or Unity pacing (FSR Frame Generation: the native frame-start guard, shown as "Frame-start guard" in the overlay); an extra guard enforces the cap when VSync causes Unity to ignore it, including with DLSS Off. |
| Cost Profiling | On/Off | `[Diagnostics] Profiling`. Applies immediately: `PROFILING on; see profile.log` in managed.log, then a `profile.log` block every 2 s. Independent of Logging Level. |
| Logging Level | Off, Error, Warning, Info, Debug | Applies immediately to the mod's BepInEx output, managed.log and native.log, including the next startup. Each level includes the more severe messages. Off stops new messages; existing messages remain. NVIDIA SDK log files are separate. |
| Enable Hotkeys | On/Off | Applies immediately to all five shortcuts. |
| Hotkey bindings | Keyboard shortcuts, including key combinations or None | Toggle Debug Overlay (F6), Cycle Upscaler Quality (F7), Capture Diagnostics (F8), Toggle Upscaling (F10), Toggle Frame Generation (F11). Applies immediately; None disables that shortcut. |

Settings live in `BepInEx/config/xanderfrangos.riskofrainupscaling.cfg`. Upscaler Quality writes `[Upscaling] Enabled` and `[Upscaling] Quality`; Frame Generation writes `[Frame Generation] Enabled` and `Multiplier`. `[Upscaling] Upscaler` and `[Frame Generation] Backend` default to Auto, so NVIDIA GPUs use DLSS and DLSS Frame Generation and other GPUs resolve to FSR. `[Frame Generation] Multiplier` saves the enabled multiplier (2–6), defaulting to 2. Upscaling runs before post-processing; it moves to the end of effects only for a camera without post-processing or, for the rest of the session, after an unsupported scene image effect. End-of-effects input is always sRGB-encoded, and UI recomposition always applies when the HUD capture is valid. `[Diagnostics] ShowOverlay` and `CaptureWhileOff` default to Off. Off preserves the last selected multiplier; F11 toggles Off/that multiplier live in D3D12 and prompts for a restart only when enabling from D3D11. The presentation runtime stays fixed for the session. Disabling generation retains the running D3D12 bridge and Reflex pacing; re-enabling resumes generation with the saved multiplier when rendering is eligible. Restarting with Off saved starts D3D11, which cannot enable generation live. Reverting a pending enable request to Off cancels its restart prompt. The BepInEx preferences control runtime loading, presentation mode and multiplier. Reconstruction changes requested during Capture Diagnostics wait for that capture to finish.

The native runtime checks NVIDIA's `numFramesToGenerateMax` before selecting a multiplier, then requests multiplier minus one generated frames per rendered frame. See [NVIDIA's multi-frame integration guide](https://github.com/NVIDIA-RTX/Streamline/blob/2122257e0fce486f91b385aa63b9a09b0a34b363/docs/ProgrammingGuideDLSS_G.md#62-enabling-multi-frame-generation). Availability depends on the GPU, driver and NVIDIA runtime; selecting 6x cannot add support to a system that reports a lower maximum.

Framerate Limit reads/writes the game's `fps_max` setting directly, including its saved requested value while Reflex owns pacing. The game saves this setting. Turning DLAA/DLSS Off with F10 or the quality menu restores the game's normal limiter with the latest requested cap on the next frame; re-enabling reconstruction resumes Reflex pacing when eligible. Frame Generation Off alone (F11) retains Reflex pacing while reconstruction is enabled. The earlier separate BepInEx `Display.Framerate Limit` override is no longer used and cannot overwrite the game's setting at startup or shutdown.

Risk of Options is an optional runtime dependency. Without it, configuration and hotkeys still work. The DLL is a build reference and is not bundled. `build/Build.ps1` locates it in the build profile, or accepts `-RiskOfOptionsPath` with `-UseCachedReferences`.

## Game checks (pending)

1. Open Mod Options in the title menu and in a run. Check all graphics, logging and hotkey controls and the exact choice labels. Switch Upscaler between Auto, DLSS and FSR in a run: the overlay's `SR` label must follow on the next frame. Change Frame Generation Backend and confirm the restart prompt; after restarting, the overlay's `FG` label shows the new backend.
2. Cycle all quality choices, including Off, and verify the world/HUD render correctly without restarting. Check F7/F10 and native-failure fallback agree when reopening the menu.
3. Start with Frame Generation Off. Confirm D3D11 presentation and no D3D12 bridge creation. Select 2x, apply the change and confirm the restart prompt; the running session must remain D3D11/Off. Revert to Off and confirm no further prompt. Restart with an enabled choice saved, confirm D3D12 presentation and actual SDK presents when eligible. Select Off: confirm no restart dialog, generation stops, and D3D12 presentation remains active. Select 4x: confirm it enables in-game without restarting. Repeat using F11. Restart with Off saved and confirm D3D11 again requires a restart to enable generation.
   While enabled, cycle 2x → 4x → 6x → 3x → 2x without restarting. Confirm no restart dialog, and check `FRAME_GEN_MULTIPLIER`, `FRAME_GEN_ENABLED` and the overlay show the effective multiplier on the next eligible frame. Test Off/on and multiplier changes while paused/unfocused, then resume. Unsupported selections must fall back without an SDK error. With a stable base FPS cap and VSync off, verify generated output using an external frame counter. The game's FPS counter continues counting rendered frames.
4. With DLAA/DLSS active, change RCAS from 0 to 1 to 0.2. Verify a visual change, stable HUD/alpha, `RCAS_CHANGED` and no reconstruction-history reset caused by sharpening.
5. Change the game's normal FPS limit, then open Mod Options and confirm the same value. Change Mod Options to 30, 60 and -1 (unlimited), then confirm the game's normal menu matches. Test with 2x on/off, paused, unfocused and with VSync. Restart and confirm the game saves the latest shared value.
6. Change Logging Level through Off, Error, Warning, Info and Debug. Confirm Off stops new messages in BepInEx and the mod log files, Error retains failures, Warning adds warnings, Info adds status, and Debug adds camera/render traces. Switch back from Off and confirm output resumes. Restart with Off saved and verify startup messages are suppressed. Use Debug when collecting detailed rendering evidence; NVIDIA SDK files are separate.
7. Rebind each shortcut and apply it. Confirm the new binding works, the previous binding no longer triggers that action, and overlay hints show the saved bindings. Check a key combination, None for an individual action, and the global Enable Hotkeys switch. While the rebind dialog is listening, keys must not trigger mod actions. Restart and verify all selections persist.
8. Start without Risk of Options and verify startup/config/hotkeys still work.

Managed regression tests check every logging threshold and BepInEx severity, hotkey defaults, key combinations, disabled bindings, and saved/reloaded preferences. Native logging tests check Off before initialization, all five thresholds and live changes. Managed regression tests also exercise fresh defaults and section names, all quality/FG choices, live D3D12 Off/on and multiplier eligibility, D3D11 enable restart behavior, hotkey consistency, notifications, limits and persistence. Startup fixtures verify all multipliers, invalid values, and rejection of live enablement after an Off startup. Native tests cover GPU capability fallback. `build/Test.ps1 -FrameGeneration -ReflexLimiter` runs each multiplier plus live changes up/down and Off/on on the same runtime, verifies actual SDK frame counts and retained D3D12 presentation, and checks Reflex pacing, resize, suspension and recreation. These fixtures do not replace the game checks above.
